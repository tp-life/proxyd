# 管理导航与远程访问规划

## 目标与分层

顶部横向大类为「总览、代理、远程访问、系统」，左侧只显示当前大类的二级页面。二级页面按用户任务划分。导航、命令搜索与 URL 路由共用注册表；新增业务功能先归入现有任务页，只有独立管理对象才增加二级页面，避免为每个开关新增菜单。

远程访问仍属于 remote 上下文。SSH 授权是其中独立的策略服务：配置保存公钥、禁用状态和到期时间；运行态负责逐次认证、会话索引和审计；application 编排配置事务；API/CLI/Web 只表达管理意图。

## 本轮实现

1. SSH 公钥支持禁用、恢复和到期时间，按认证发生时刻判断，不依赖清扫任务。
2. 公钥策略热更新，不重建隧道或变更 token；默认只影响新认证，管理员可另外断开指定公钥已有连接。
3. 最近成功认证时间、活动连接数和有界审计记录；密钥探测不计作成功登录。记录范围与重启行为在界面明确说明。
4. 客户端 SSH 诊断分阶段输出，使用现有 OpenSSH 私钥/agent 能力，不上传私钥；诊断采用有限超时，失败后不给出虚假的后续成功结果。

## 模块生命周期与全局会话

代理与远程访问仍是独立 bounded context。模块开关是配置聚合的生命周期状态；application 负责事务与跨模块桌面会话清理，不复制 SSH、代理或中继规则。remote Manager 通过可取消的运行期上下文管理入站连接、临时转发与终端；终端另有独立取消范围。Web 根组件持有终端会话，页面只提交打开意图。

“系统 → 模块管理”和业务侧栏均可启停模块，CLI 为 `proxyd modules proxy|remote on|off`。配置使用 `proxy-disabled` 与 `remote.disabled`，默认 false，兼容旧配置。它们与已有服务端 `remote.enabled`、`builtin-ssh` 等子开关分离。禁用保留业务配置，结束现有连接；重新启用恢复监听与原设置，不重放已结束的交互会话。纯远程实例可设置 `proxy-disabled: true`，无需代理订阅。

Web Terminal 最小化固定在右下角，跨大类切换保留同一 WebSocket、PTY 和滚动缓冲；恢复重新测量网格，关闭才断开。当前每个浏览器标签页保留一条会话，重复打开入口会恢复当前会话。刷新或关闭浏览器仍会结束连接。

DERP 自动发现优先复用 `<state-dir>/remote/derp-region.json`，没有缓存时依次尝试 tailcat 默认地图与 Tailscale 官方地图；自定义地图不使用公共回退。自动区域持久化防止跨重启 token 漂移。开机失败保留可见错误，每 30 秒重试（每轮发现最多 15 秒），模块停用时停止重试。缓存区域不能代替可达网络；需主动重新选区时先停止服务、删除该区域缓存、再启动，并重新分发可能变化的 token，保留身份密钥文件。

## 后续落位

UDP 转发与远端内网地址放到「端口转发」；PSK 状态、显式迁移/轮换和 GitHub 公钥导入放到「访问授权」。这些是后续规划，本轮不以空菜单占位。

已修复 mihomo v1.19.30 的日志级别及入站 IP 策略竞态，采用本地依赖替换并保留上游源码和许可证。当前生命周期、配置历史、代理核心、application、API、remote 和 CLI 包的竞态检查全部通过；补丁位置和升级方法见 [第三方补丁说明](../third_party/README.md)。

本轮没有在用户的 home 远端部署或执行诊断；需更新并重启对应服务端后使用新子系统。UDP、远端局域网目标与 PSK 管理仍按上表作为后续工作。

新增验证：模块开关覆盖真实代理监听释放/恢复、停用期间刷新隔离、配置落盘回滚、终端/临时转发/入站连接取消，以及 HTTP 参数边界。浏览器覆盖顶部大类、移动端子菜单、实际 WebSocket 最小化后跨大类恢复和关闭。

系统大类新增“诊断中心”和“配置历史”。远程访问的设备、服务、授权、转发、审计面板位于 `web/src/components/remote/`，共享连接对话框与展示函数集中在 `RemoteConnectionTools.jsx`。根页保留跨子页表单状态与用例传参，全局终端仍由 App 持有。

禁用代理或远程访问模块后，对应顶部大类、侧边子菜单和命令搜索项隐藏；代理快捷操作同时隐藏。当前页面属于被禁用模块时自动转到“系统 → 模块管理”，直接访问旧链接或浏览器后退也遵循同一规则。模块管理入口始终保留，重新启用后菜单恢复。首次尚未取得模块状态时暂不显示模块大类，以免禁用菜单短暂闪现。


## 全局总览与代理运行概览

默认 `#/overview` 展示全局总览；原有主入口策略、流量图和快捷设置迁入 `#/proxy/overview`，作为代理大类首个子页。总览不显示侧边栏，命令搜索与主题切换保留在页头。禁用模块不显示卡片或模块待办，全部禁用时引导到模块管理。

总览是只读展示组合，不新增业务聚合或改变代理、remote 的领域规则。`web/src/lib/dashboard.js` 按模块注册摘要投影，统一输出指标、状态和处理入口；`useDashboardFeed` 负责 HTTP 读取、取消与局部失败反馈；页面不依赖 SDK。系统运行时长与待重启状态由 application 用例通过 `GET /api/system/status` 提供，不读取配置历史正文。

代理摘要包含模式、可用节点、活动连接、实时速率；远程摘要区分服务端开关、模块状态、保存的设备、入站连接、运行中转发与桌面会话。不以设备档案数推断在线数，也不将 SSH 授权计数叠加到隧道连接数。Web Terminal 继续使用已有右下角会话栏。

待办包含模块失败/重试、无已确认可用代理节点、远程服务与转发故障、未禁用 SSH 密钥到期或 7 天内到期、配置等待重启。禁用模块的旧异常不参与统计。摘要接口各自失败隔离，8 秒超时，完成一轮后间隔 10 秒再读取；离开总览取消请求，禁用代理同时停止流量订阅。缺失指标显示未知，避免把读取失败误报为零连接或健康。
