# ADR 0001：区分配置意图、运行观测与历史恢复

状态：已采用。

模块开关不足以表达启动失败、部分能力可用及等待网络恢复。配置修改也需要可恢复证据，但普通历史 JSON 不应留下完整凭据。

采用独立生命周期聚合，以世代号拒绝过期观测。远程维护独立调度，避免订阅刷新阻塞重试。Web 与 CLI 的统一诊断使用固定结构和提示；需要客户端私钥的场景继续使用原生 SSH 诊断命令，不将客户端凭据迁移到守护进程。

配置版本仓储接口放在独立领域包，本机实现使用 AES-GCM 和专用密钥。保存前归档磁盘原文，恢复时才进行完整业务校验，允许用户修复不满足新规则的旧配置。公开下载使用单独脱敏副本，未通过当前版本校验时只返回说明。

恢复采用“预检目标摘要＋当前磁盘摘要”乐观并发控制。恢复前归档，恢复后要求重启，期间禁止旧运行配置落盘。代价是不能立即热恢复整份配置，但能保持管理地址、状态目录、身份引用等跨模块变更的一致启动语义。历史不备份独立身份文件。

当前 mihomo 依赖的异步读路径无法由应用外围锁保护，使用本地完整上游源码加少量同步补丁，保留许可证和明确升级说明；待上游修复后移除替换。
