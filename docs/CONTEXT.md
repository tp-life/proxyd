# proxyd 领域上下文

代理（proxy）拥有订阅、节点、端口映射和代理核心；远程访问（remote）拥有设备、隧道身份、SSH 授权、转发与会话。模块启用状态属于配置意图，生命周期快照属于运行观测，二者不可混为一个布尔值。

生命周期（lifecycle）以模块为聚合边界，维护运行阶段和尝试世代；较早操作的结果不能覆盖新世代。诊断（diagnostics）以一次报告为聚合，检查步骤为值对象，保留脱敏结果；DNS、SSH 和 SDK 探针放在适配实现。配置版本（configversion）以不可变版本 ID 为实体标识，仓储接口负责归档、列表、恢复读取和脱敏导出。

application 编排配置事务、诊断与恢复；API、CLI 与 Web 调用同一用例。配置历史文件与加密实现在 infrastructure/confighistory。远程第三方适配仍按当前项目约定集中在 internal/remote，纯诊断报告和生命周期包不导入 tailcat、HTTP 或数据库。

前端导航注册表决定大类与子菜单。远程访问根页保留共享表单状态，独立面板负责展示，各数据 hook 编排请求；终端宿主在根应用中，页面切换不会卸载活动终端。
