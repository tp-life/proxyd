概览

已映射端口

代理模式（主端口）

主端口使用最优节点已开启，模式切换对主端口不生效

主端口

规则模式入口；保存后立即热更新，系统代理开启时自动重绑

开启后主端口跳过规则、直连最优节点（与自动选优端口并存，互不影响）

不开优选时可把主端口固定到指定节点（跳过规则）；节点失效时自动回退规则模式，恢复后自动再生效

节点映射端口区间

— 保存后立即重新分配端口并热更新

自动选优端口

独立端口固定走延迟最低的可用节点，与主端口互不影响

系统代理

关闭 proxyd 前请先在此关闭，或用 proxyd sysproxy off 恢复

开机自启

也可用 proxyd autostart on|off|status 管理

订阅与节点

手动节点（自有代理：http(s)/socks5 URL 或 ss/vmess 等分享链接，落盘到配置文件）

订阅

端口映射（每端口固定走对应节点）

端口 节点 订阅 延迟 状态

自定义规则

规则逐条前置到内置规则之前，先生效。支持 DOMAIN / DOMAIN-SUFFIX / DOMAIN-KEYWORD / IP-CIDR / GEOSITE / GEOIP 等 mihomo 规则语法，格式 类型,内容,策略，策略可填 DIRECT / REJECT / 节点名 / 分组名。

    规则 URL（跟随订阅刷新拉取，支持 mihomo 规则文本 / gfwlist）

      节点分组（一组节点 → 指定端口，自动选优）

      分组成员取所选节点与当前可用节点的交集；组内按延迟自动选优（url-test）。失效节点也可勾选，恢复后自动加入。

        仅影响下方待选列表的显示顺序，不影响已保存分组
